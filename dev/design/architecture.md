## 2. 总体架构

```
┌─────────────────────────────────────────────────────────┐
│                    平台壳（Platform Shell）              │
│  ┌───────────────┐   ┌──────────────────────────────┐   │
│  │ 渲染进程       │   │ 主进程（Platform Core）        │   │
│  │ React + TS    │◄─►│ · 应用注册表/应用中心           │   │
│  │ 极简现代风 UI  │IPC│ · 窗口与进程管理               │   │
│  └───────────────┘   │ · 共享数据服务（SQLite）        │   │
│                      │ · 设置/日志/更新               │   │
│                      └──────────┬───────────────────┘   │
└─────────────────────────────────┼───────────────────────┘
                                  │ 桥接 API（App SDK）
          ┌───────────────────────┼───────────────────────┐
          ▼                       ▼                       ▼
   ┌─────────────┐        ┌─────────────┐        ┌─────────────┐
   │  应用 A      │        │  应用 B      │        │  应用 C      │
   │ 独立窗口进程 │        │ 独立窗口进程 │        │ 独立窗口进程 │
   │ (app/xxx)   │        │ (app/yyy)   │        │ (app/zzz)   │
   └─────────────┘        └─────────────┘        └─────────────┘
```

- **平台壳**：应用中心（安装/卸载/启动/搜索）+ 平台设置。是用户的主要入口。
- **应用进程**：每个应用独立 BrowserWindow + 独立进程，崩溃互不影响，可多开并排。
- **App SDK**：统一桥接 API，应用只能通过 SDK 访问平台能力与共享数据。

## 3. 平台核心模块

### 3.1 应用中心（App Registry）
- 应用注册表：应用元数据（id、名称、图标、版本、入口、权限），存于 SQLite + 应用清单文件
- 功能：安装（本地包/后续远程源）、卸载、启动、搜索、更新检查

### 3.2 应用运行时（App Runtime）
- 每个应用 = 独立 BrowserWindow，独立 `session` partition（安全隔离）
- 应用包结构（草案）：

```
app-package/
├── manifest.json      # id、名称、版本、图标、入口、所需权限
├── main.js            # 应用前端入口（加载自有渲染页面）
├── preload.js         # 应用 preload（封装 SDK 调用）
└── assets/            # 图标、静态资源
```

- 安装位置：`%APPDATA%/SciTool/apps/<app-id>/`

### 3.3 App SDK（桥接 API）
应用通过 preload 暴露的 SDK 访问平台能力（MVP 范围）：
- `sdk.storage`：应用私有键值存储
- `sdk.sharedData`：跨应用共享数据（接口预留，schema 后置，见 D5）
- `sdk.settings`：平台设置读取
- `sdk.i18n`：平台语言与本地化资源
- `sdk.log`：统一日志
- `sdk.ui`：窗口控制、通知

### 3.4 共享数据基础设施
- SQLite（`better-sqlite3`）存储平台数据；共享数据表结构**后置**（开发具体应用时设计）
- MVP 仅提供：应用私有存储 + 共享数据 API 通道（占位实现）

### 3.5 其他
- 设置中心：语言（中/英）、主题（浅色优先，暗色后续）、数据目录
- i18n：`i18next` + `react-i18next`，中英文案资源随开发同步维护
- 日志：主进程与应用进程日志统一落盘

## 4. 技术选型细节

| 项 | 选择 | 说明 |
|----|------|------|
| 桌面框架 | Electron（最新稳定版） | 成熟、Node 后端契合开发者背景 |
| 前端 | React 18+ + TypeScript | 已确认（D6） |
| 构建 | electron-vite | 现代、快速、TS 开箱即用 |
| UI 组件 | Tailwind CSS + 自研组件库（shadcn 风格） | 极简现代风可控性最高 |
| 数据库 | better-sqlite3 | 同步 API、成熟；需 electron-rebuild 原生模块 |
| i18n | i18next | 生态最成熟 |
| 打包 | electron-builder（NSIS 安装器） | Windows 标准分发 |
| 包管理 | npm workspaces（或 pnpm） | monorepo：platform + sdk + apps/* |
| 状态管理 | zustand | 轻量现代 |

## 5. 安全设计

- `contextIsolation: true`、`nodeIntegration: false`、`sandbox` 按应用权限开启
- IPC 白名单：应用仅能调用 SDK 暴露的通道
- 应用权限清单：manifest.json 声明所需权限，平台在安装/运行时校验
- 每应用独立 session partition，互不共享 Cookie/存储
- CSP 严格策略；远程内容默认禁用

## 6. 仓库目录结构（monorepo 草案）

```
SciTools/
├── dev/                    # 开发管理（现有）
├── packages/
│   ├── shell/              # 平台壳（Electron 主进程 + React UI）
│   │   ├── src/main/       # 主进程：应用中心/运行时/SDK 服务
│   │   ├── src/preload/    # 壳层 preload
│   │   └── src/renderer/   # React 应用中心 UI
│   ├── sdk/                # App SDK（应用侧调用封装，类型定义）
│   └── apps/               # 未来具体应用（当前为空，见 D6）
└── ...
```
